Here are some of my open-source experiments and demos:

#### Java Core & Algorithms 
* [stream-template-engine](https://github.com/AlekseyBykov/stream-template-engine) — Lightweight reusable Java library for streaming placeholder replacement.
* [wordle-game](https://github.com/AlekseyBykov/wordle-game) — Wordle game implementation with clean architecture, dictionary indexing, and comprehensive unit tests.
* [sleep-tracker-analyzer](https://github.com/AlekseyBykov/sleep-tracker-analyzer) — Analysis tool for analyzing sleep logs and calculating sleep-related metrics.
* [movie-catalog-api](https://github.com/AlekseyBykov/movie-catalog-api) — Lightweight Java 21 REST API built with JDK HttpServer and Hexagonal Architecture.

#### Microservices & Distributed Systems
* [cloud-marketplace](https://github.com/AlekseyBykov/cloud-marketplace) — Microservices-based platform demonstrating modern backend architecture and system design.
* [edu-sphere](https://github.com/AlekseyBykov/pets.edu-sphere) — Microservice-based system with API gateway and containerized deployment.
* [event-driven-demo](https://github.com/AlekseyBykov/pets.event-driven-demo) — Event-driven microservices using RabbitMQ.
* [payment-ttl-dlx](https://github.com/AlekseyBykov/pets.payment-ttl-dlx) — Message TTL and DLX patterns for delayed processing and expiration.

#### Release Automation Tools
* [patchcraft-web](https://github.com/AlekseyBykov/patchcraft-web) — Microservice-based system for automated patch generation, notifications, and integrations.
* [patchcraft-desktop](https://github.com/AlekseyBykov/patchcraft-desktop) — Desktop tool for patch creation, impact analysis, and delivery workflows (Go + Wails).
* [relmgr](https://github.com/AlekseyBykov/pets.relmgr) — JavaFX desktop application for release management, patch packaging, and communication workflows.

#### Architecture & Backend Design
* [spring-boot-monolith](https://github.com/AlekseyBykov/pets.spring-boot-monolith) — Layered monolith architecture example.
* [onion-architecture](https://github.com/AlekseyBykov/pets.onion-architecture) — Onion architecture with strict domain separation.
* [sdk-api-demo](https://github.com/AlekseyBykov/pets.sdk-api-demo) — Custom rate limiter with scheduled sender.

#### Data Processing & Enterprise Integration
* [pipespec](https://github.com/AlekseyBykov/pets.pipespec) — ETL module for flat-file parsing, XML validation, and domain mapping.
* [querydsl-demo](https://github.com/AlekseyBykov/pets.querydsl-demo) — QueryDSL usage with Spring Boot and Testcontainers.

#### Testing & Diagnostics
* [autotests-app](https://github.com/AlekseyBykov/pets.autotests-app) — Automated test runner with Excel-based scenarios and reporting.
* [diagnostic-lab](https://github.com/AlekseyBykov/pets.diagnostic-lab) — JVM diagnostics: thread dumps, heap dumps, GC analysis.
* [oracle-index-utils](https://github.com/AlekseyBykov/pets.oracle-index-utils) — Idempotent Oracle index creation with Testcontainers-based validation.

#### AI & Experiments
* [spring-ai-chat](https://github.com/AlekseyBykov/pets.spring-ai-chat) — REST API with local LLM integration (Ollama, Mistral).

#### Certificates
* [certificates](https://github.com/AlekseyBykov/certificates) — Collection of completed courses and certifications.
